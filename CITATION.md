# How to Cite This Project

Thank you for citing the software when it contributes to research, teaching, evaluation,
or a derivative project.

## Software citation

Recommended plain-text citation:

> Begum, S. (2026). *Equitable Capital Optimization AI* (Version 0.4.0) [Computer software]. GitHub. https://github.com/sakera023/equitable-capital-optimization-ai

GitHub can also generate citation formats automatically from
[`CITATION.cff`](CITATION.cff) through the repository's **Cite this repository** menu.

## BibTeX

```bibtex

  author       = {Sakera Begum},
```
