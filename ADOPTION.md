# Adoption and External Use

This project is designed to be useful to researchers, educators, developers, economic
development practitioners, and organizations studying responsible AI and small-business
capital access.

## Ways to use the project legitimately

You can:

- install the Python package from PyPI;
- run or fork the GitHub repository;
- use the Jupyter examples in teaching or research;
- test the live Streamlit dashboard;
- reproduce the benchmark workflow;
- inspect or extend the public SBA data layer;
- reuse the research architecture under the MIT License; and
- cite the software in academic or technical work.

## Tell us how you used it

External use is most useful when it is verifiable and specific.

If you use the project, consider opening a GitHub issue using the **Research / Adoption
Report** template. Useful information includes:

- organization, course, research group, or project name, if you are comfortable sharing it;
- what part of the repository you used;
- whether you installed the PyPI package or used the live app;
- what worked well;
- limitations you found;
- whether you created a derivative implementation; and
- a public link to a paper, syllabus, repository, report, or demonstration when available.

Do not post confidential business information, applicant records, private datasets, or
personal data.

## What counts as meaningful adoption evidence

Examples include:

- a public repository that imports or extends the package;
- a paper, preprint, report, poster, or class project that cites the software;
- a reproducible issue describing use in a research or teaching workflow;
- a pull request from an external contributor;
- a public organization or laboratory demonstration;
- a documented bug report based on real technical use; or
- a business or research letter that accurately describes actual use.

Stars, follows, or unsupported testimonials should not be treated as evidence of impact.

## Maintainer policy

The maintainer will not create fake users, fake stars, fake citations, or fabricated
testimonials. External-use claims should be traceable to genuine activity whenever
possible.
