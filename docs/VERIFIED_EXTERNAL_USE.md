## Evidence standard

A future entry should be supported by at least one traceable source such as:

- an independent repository or notebook;
- a paper, report, thesis, poster, or syllabus;
- an attributable external GitHub issue or pull request based on real use;
- an independent replication report;
- a public presentation or demonstration; or
- accurate documentation of organizational testing or use.

Repository stars, follows, outreach messages, unverifiable screenshots, or fabricated
testimonials are not sufficient evidence.

## Adding an entry

Before adding an entry:

1. verify that the user or organization is genuinely external to the maintainer;
2. preserve the underlying evidence;
3. describe only what was actually used or tested;
4. avoid converting technical use into a broader endorsement; and
5. link public evidence where available.

See [Independent Replication Protocol](INDEPENDENT_REPLICATION.md) and the repository's
[ADOPTION.md](../ADOPTION.md).
